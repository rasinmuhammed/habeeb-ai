# Habeeb AI - Your AI-Powered Coding Companion 🤖❤️

**Habeeb** (حبيب) means *beloved* or *dear friend* in Arabic. Inspired by this, **Habeeb AI** is designed to be your trusted AI companion, helping developers collaborate, analyze, and optimize workflows with intelligence and ease.

---

## 🚀 Features

- **AI-Powered Meeting Analysis**: Transforms meeting discussions into structured insights and action items.
- **Intelligent Issue Tracking**: Automatically extracts key points from discussions and converts them into trackable issues.
- **GitHub Integration**: Syncs projects with GitHub for seamless development collaboration.
- **Summarize Each Commits**: A short summary of the changes made in each commit is displayed.
- **🔍 Ask the Code (RAG-Powered Q&A)**: Utilize **Retrieval-Augmented Generation (RAG)** to query your codebase and get instant AI-powered answers to development questions.
- **Team Collaboration**: Effortlessly invite team members and manage access.


---

## 🛠️ Tech Stack

- **Frontend**: Next.js 15, Tailwind CSS
- **Backend**: Next.js API Routes, Prisma, tRPC
- **Database**: PostgreSQL with PGVector for AI-powered retrieval
- **AI Services**: LangChain, Google's Gemini AI
- **Authentication**: Clerk
- **Hosting**: Vercel

---

## 📦 Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/rasinmuhammed/habeeb-ai.git
   cd habeeb-ai
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Set up environment variables:
   - Copy `.env.example` to `.env`
   - Fill in the required values

4. Run the development server:
   ```sh
   npm run dev
   ```
